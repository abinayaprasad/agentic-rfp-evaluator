# RFP Response Template

Use this structure for any supplier proposal you want the evaluator to score. The
Evaluation Agent works best when each of the six sections below is present with a
clear heading, because every section maps to one or more scoring criteria.

> Save the finished document as a **text-based PDF** (exported from Word, Google Docs
> or similar). Scanned images have no text layer and will be rejected with the
> `PDF_TEXT_TOO_SHORT` warning. Aim for 2–6 pages.

## 1. Executive Summary and Understanding of the Requirement
*Scored under: all criteria (context), mainly Technical Capability*

- Restate the buyer's situation and goals in your own words (studies, countries, systems to replace, deadline).
- State your proposition in two or three sentences.
- Name the key risks you see for the buyer and where in this document each is addressed.

## 2. Proposed Solution and Implementation Approach
*Scored under: Technical Capability*

- Product name and architecture (hosting model, data model, configurability).
- **Named integrations** with each buyer system (eTMF, EDC, SAP/finance, identity provider): protocol, direction, frequency. Vague statements such as "we integrate with all major systems" score low.
- Reporting and dashboards included.
- Scalability statement (studies, sites, users, countries).

## 3. Timeline, Team Structure and Milestones
*Scored under: Implementation Plan*

| Wave / Phase | Scope | Months | Exit criteria / milestone |
|---|---|---|---|
| | | | |

- Migration strategy for legacy data, including rehearsal migrations.
- Validation activities (IQ / OQ / PQ) and who owns them.
- Team roles with FTE allocation and relevant prior experience.
- Risk register: at least three risks with mitigations.
- Training, change management and hypercare duration.

## 4. Pricing and Assumptions
*Scored under: Commercial Value*

| Item | Year 1 | Years 2–5 (each) | 5-year total |
|---|---|---|---|
| Subscription / licence | | | |
| Implementation and migration services | | | |
| Validation services | | | |
| Integration services | | | |
| Support and hypercare | | | |
| **Total** | | | |

- Pricing model (per study, per user, platform fee) and currency.
- Every assumption behind the numbers (volumes, buyer responsibilities, travel, uplift caps).
- What is excluded and how it would be priced.

## 5. Security, Compliance and Risk Controls
*Scored under: Security & Compliance*

- Regulatory: 21 CFR Part 11 / EU Annex 11 audit trail and electronic signatures.
- Validation package provided (IQ/OQ/PQ protocols, traceability matrix, validation summary report).
- Certifications with identifiers (ISO 27001, SOC 2 Type II) and audit cadence.
- Data protection: GDPR, data residency options and locations, DPA / SCCs, HIPAA where relevant.
- Access control, segregation of duties, MFA, encryption in transit and at rest, penetration testing.
- Backup, retention and disaster recovery.

*Scored under: Support & Experience*

- Support hours and channels, availability commitment and service credits.
- Hypercare duration and named roles after go-live.
- Relevant experience: number of comparable deployments, years in market, regulatory inspection history.
- References: at least three comparable customers (name, scope, year), with contact available on request.

### Checklist before submitting

- [ ] Every section above has a heading and content
- [ ] Integrations are named, not generic
- [ ] Timeline has waves/phases with exit criteria
- [ ] Price table totals are consistent and assumptions are listed
- [ ] Regulatory controls are stated explicitly (Part 11, GDPR, ISO 27001)
- [ ] SLAs, hypercare and references are specific
- [ ] Exported as a text-based PDF, not a scanned image
- [ ] No real confidential data (for classroom use, all content is fictional)
